# 🚀 AI Website

A modern, responsive AI website built using HTML, CSS, and JavaScript. This project features a premium user interface with smooth animations, responsive layouts, and interactive components designed for AI products, SaaS platforms, startups, and technology businesses.

## ✨ Features

- Modern and responsive UI
- Premium landing page design
- Smooth CSS animations
- Interactive navigation
- Product showcase section
- Solutions section
- Developer section
- Security section
- Pricing section
- Company overview
- Resources section
- Professional footer
- Mobile-friendly layout
- Clean and organized code structure

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/shubhamkokitkar-crypto/AI-Website.git
```

### Open the project

```bash
cd AI-Website
```

Open `index.html` in your preferred web browser.
